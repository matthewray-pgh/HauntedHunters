# SHORT 07 — Field Dispatch
## "Mining Crew Radio Check, 1968"

### Format
Field Dispatch (revised from Classified Transmission — no more black
screens, see `short_form_content_system.md` v4.0)

### Date
Sunday, September 13, 2026

### Runtime Target
15–20 seconds

### Connects To
Black Vein atmosphere — no new information, pure period-piece tension.

---

### Production Notes

**Midjourney Image Generation**
Not the Dispatcher this time — a period-appropriate mine radio setup,
no person needed, since the tension here comes from the equipment
itself going quiet rather than a character reacting to it:

```
1960s analog mine communications radio set on a wooden desk inside a
site office trailer, single work lamp casting warm light, dial gauges
and switches worn from handling, small speaker grille, window behind
showing dark mine entrance lit by one floodlight in the distance,
painterly dark illustration, concept art style, highly detailed
brushwork, textured paint surface visible, cinematic dark fantasy
illustration, teal and amber palette, period-accurate equipment, no
people, atmospheric tension
--ar 9:16 --style raw --stylize 780
```

**Runway ML Animation**
- Motion: radio dial needle flickers/twitches slightly during dialogue,
  work lamp flickers once during the static burst
- Duration: 15–20 seconds, runs the full clip

**ElevenLabs Audio**
Two voices:
- Voice A (Foreman): flat, period-appropriate radio processing, slight
  wow/flutter matching 1968 equipment
- Voice B (Surface Dispatch): similar processing, calm, procedural

Heavy static/radio degradation on both.

**Script**
```
FOREMAN (V.O., radio processed):
Surface, this is Tunnel Four. Radio check.

[STATIC BURST — lamp flickers]

DISPATCH (V.O., radio processed):
Copy, Tunnel Four. Go ahead.

FOREMAN (V.O.):
We've got — the wall's reading wrong on the sonar again. Same as
yesterday.

[LONG PAUSE — radio dial needle twitches, static continues]

DISPATCH (V.O.):
Say again, Tunnel Four?

[NO RESPONSE — static continues, dial needle stops moving entirely]
```

**CapCut Assembly**
- Radio set image plays throughout — no black screen at any point
- Classification stamp small, top corner: RECOVERED AUDIO / APPALACHIAN
  REGION — 1968
- Text appears word by word as audio plays, lower third
- Static burst as a visual glitch over the image between voices
- Hold on the still radio, dial needle motionless, for 2 seconds before
  cut

### On-Screen Text
Word-by-word sync with dialogue, pale off-white (#DCE6D6), lower third.

### Caption
```
recovered radio log. tunnel four. 1968.

#ObsidianFrequency #AnalogHorror #ParanormalLore #fyp
```
