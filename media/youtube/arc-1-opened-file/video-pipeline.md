## Runtime Target (REPLACES prior 6-8 min standard)

**8-10 minutes is the new standard target across all Arc 1 videos**,
with two named exceptions (Video 11, Video 13 — see below).

This clears the YouTube mid-roll ad threshold (8:00) with real margin,
rather than sitting at the edge where a slightly-tight edit falls back
to pre/post-roll only. It also resolves the prior inconsistency between
this document's old 6-8 min target and `content-bible.md`'s separately
stated 8-15 min ad-eligibility range — 8-10 min sits inside both.

**This is a script-length change, not a pacing change.** Runtime should
come from word count, per the existing house philosophy below — do not
hit the new target by further stretching BEAT/LONG BEAT holds or slowing
Ken Burns pans. That path was already tested on Video 02 and judged to
feel padded before the runtime gap was even closed.

## Word Count Guide (REVISED)

At 100-120 words per minute (slow, deliberate narration pace):

- 8 minutes = ~800-960 words
- 9 minutes = ~900-1080 words
- 10 minutes = ~1000-1200 words

Write scripts to word count, not to time. Time will follow.

## Named Exceptions — Do Not Apply 8-10 min Target

**Video 11 — Recovered Log: Echo-4:** No Archivist narration; runtime is
driven by dialogue, silence, and degraded audio pacing, not a word
count. Still targets a longer runtime consistent with the arc (treat
8-10 min as a rough guide for total edit length), but "add more words"
is not the lever here — expansion means additional scripted dialogue
beats, comms exchanges, or extended silence/tension holds, decided
separately from this word-count system.

**Video 13 — File Zero:** Explicitly exempted. Runtime stays 4-6 min.
Per the existing script note: *"Do not pad this video. Do not add
content to make it feel more complete. Restraint is the statement."*
Forcing this video to 8-10 min would undermine the entire point of the
arc's closing beat. This exception is intentional and should not be
revisited without revisiting the finale's core concept.

## Complexity note

Raising word count on the low-complexity videos (04, 08, 09, 10, 12)
doesn't necessarily mean raising their production complexity rating —
more document/narration content can often be added within the existing
single-visual-system approach (e.g. additional document sections, more
detail in an existing faction dossier) rather than requiring new visual
systems. Complexity ratings should be revisited only if the additional
content genuinely requires new assets (a second visual system, more
images), not automatically alongside the word count increase.
