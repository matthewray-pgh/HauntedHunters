# Script Notes

## Runtime Target
8–10 minutes | ~820–950 words of narration

*(Expanded from the original 6–7 min / ~650–780 words per the Video 07
script-expansion patch — ~170 words of new narration added across three
insertion points, one at the end of each body section (Classification,
Known Behaviors, Environmental Effects). Narration only — no testimony
card, no surveillance insert, no second visual system, all over the
existing fragmented document. Estimated runtime after expansion
~7:45–8:30 at the deliberately slow pacing, before the closing
annotation's extended hold — "the longest pause in the arc so far" —
which is NOT to be compressed and pushes runtime further into band. If
it still reads short after BEAT tuning, add one more short beat inside
Insertion 3 (Environmental Effects, the largest section).)*

## Complexity
3/5 per video-pipeline.md.

## One Job
Establish that some things cannot be contained — only documented. This is
where the world stops feeling manageable. Do not let production spectacle
undercut this — the previous entity files (HH-013, HH-016) had mechanics
you could survive by following rules. This one does not offer that
comfort, and the video should not pretend otherwise.

## Continuity Requirements — Read Before Writing Any Further Draft
This video pays off a reference planted three videos ago and must land
it precisely:

- Video 03's second testimony card reads: *"Something was standing at
  the end of Tunnel Four. It did not move. It did not need to."* That
  video's production notes state explicitly this entity "stays unnamed
  here and stays unnamed in every video until Video 07." **This is
  Video 07.** The line should be echoed, not just referenced abstractly
  — the audience should feel the loop close.
- Per the outline's cut list, the Ashfall (Video 05) cross-reference
  stays to a single line only: the Hollow King is mentioned in Ashfall's
  recovered fragments as "the one the breach opens for." Do not expand
  on this — one line, no elaboration, consistent with the cut instruction.
- Per the outline's cut list, survivor account overlays (testimony-card
  style inserts, as used in Video 03) are removed from this video
  entirely. The absence of visual/testimonial evidence is the point —
  do not add a testimony card back in.

## Voice Direction
Same Archivist treatment as Videos 01–06 — ElevenLabs, tape recorder
playback, slight wow and flutter, subtle hiss, narrow frequency range.
This should be the most restrained delivery in the arc so far — quieter
than Video 04's Miner's Echo file, quieter than Video 05's frustration.
Not fear performed for the audience. Fear held very still, the way the
entity itself is described.

## Visual Approach
One visual system, fragmented rather than complete:

- **[DOCUMENT]** — the HH-020 entity classification file. Same base
  treatment as prior entity files, but the physical document itself
  should read as damaged — torn edges, missing corners, sections that
  cut off mid-sentence with no redaction bar, just absence. This is
  distinct from every previous document in the arc, which have all been
  intact even when redacted. "Fragmented" means the object itself is
  incomplete, not just the information on it.

**[FULL FRAME]** used once — silhouette only, massive scale implied
through environment and framing, never through a clear or complete view
of the figure. Per the asset list, resist any temptation to show more
than a silhouette.

No testimony cards, no surveillance insert, no secondary visual system —
per the cut list above, this video runs on absence.

## On-Screen Text
No on-screen Archivist text during narration. Closing annotation card
only.

## Silence Note
[BEAT] — minimum two seconds.
[LONG BEAT] — minimum four seconds.
Per the outline, the closing annotation carries **the longest pause in
the arc so far** — see Closing section below for the specific extended
hold time. Do not compress this to fit a runtime target; if the video
runs slightly over as a result, that is the correct tradeoff.

## First Phantom Seed — Read Carefully Before Document Design
A footnote near the bottom of the entity file references a "predecessor
entity" and has been redacted. The redaction bar covering the
predecessor's designation code is rendered **1–2 pixels too short** —
one letter is visible at the right edge of the bar, essentially
illegible at normal viewing speed but technically present in the frame.
No camera zoom, no lingering, no narration reference. This is the
subtlest seed placed in the arc so far — flag it clearly for whoever
builds the document asset, since "1–2 pixels too short" is an easy
detail to lose without a specific callout.

## Image Transition Note
Document dissolves: three seconds in, three seconds out, house standard
— though given the document's damaged/fragmented state, individual
sections may cut rather than pan smoothly where the physical document
itself is torn. Full Frame: dissolve in, hold in complete silence,
dissolve back out — no glitch, no static, no degradation effect. This
entity does not need instability in the frame to be unsettling; a clean,
steady, silent hold is the more disturbing choice here.

## Damaged Document Texture — No Additional Midjourney Prompt Needed
The torn/fragmented document appearance (missing corner, absent left
margin section) should be built as a post-processing pass in Canva over
the existing aged-paper document template already used across the arc —
not a new Midjourney-generated texture. Keep the tear edges irregular
and the missing sections genuinely blank (paper-colored background),
not blacked out — this must read as physically damaged, distinct from
every prior video's redaction-bar convention.

code is a manual asset adjustment on the existing redaction-bar element,
