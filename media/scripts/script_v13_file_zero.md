# Script Notes

## Runtime Target
4–6 minutes — shorter than every other video in the arc. Per the
outline, this is intentional. Do not pad this video. Do not add content
to make it feel more "complete." Restraint is the statement, and the
silence after the final line needs room to exist without competition.

## Complexity
3/5 per video-pipeline.md — a higher rating than the content volume
alone would suggest. The difficulty here is entirely in execution: four
to five minutes of an almost-featureless redacted document, in total
silence, has to hold attention through craft (subtle scroll pacing,
paper texture, timing) rather than through incident. A worse version of
this video is trivially easy to make and would just look broken. That
gap is the complexity.

## One Job
Arc 1 payoff. One document. One line. Silence. The channel goes quiet
after this.

## Production Order Requirement
Per `video-pipeline.md`'s Recommended Production Order: **"Video 13 —
never produce until everything else is locked."** All twelve prior
scripts are now complete, so this condition is satisfied for scripting
purposes. This note is preserved here as a reminder for the production
(filming/assembly) side, not just the writing side — do not begin actual
CapCut assembly on this video until Videos 01–12 are fully produced and
locked, not just scripted.

## A Structural Choice Worth Flagging Before Anything Else
Every prior video in this arc opens with a pre-roll text card and closes
with a watermark post-roll. **This script drops both**, and that's a
deliberate reading of the outline rather than something explicitly
spelled out in it — the outline's content list for this video contains
exactly four beats (document scroll, unredacted line, annotation,
cut to black) and nothing else. Given the "do not add content" directive
and the seed note that this video is defined by *nothing being
concealed*, I read the absence of a teaser card and a branded sign-off
as part of that same restraint, not an oversight. **This is a genuine
creative call, not a locked fact from your documents — if you'd rather
keep the four-second watermark for practical branding reasons even here,
that's a reasonable, easy adjustment and doesn't undermine anything
else in the script.**

## A Connection Worth Flagging
Video 01's orientation document features an unassigned personnel file
number, **0000**, with a pinned comment stating *"Personnel file 0000
has been open since the founding of the Directorate. It has never been
assigned."* This script uses that same file number as File Zero's own
File ID, closing the loop explicitly — the empty file from Video 01 IS
this document. **This connection is not stated outright in your video
pipeline outline; it's an interpretive choice I'm making because the
title "File Zero" and the unresolved 0000 seed line up too well to be
coincidental, and thirteen videos is exactly the right distance for that
kind of payoff.** If you already had a different plan for file 0000, or
want this connection made more explicit or left more ambiguous, that's
an easy change — flagging it clearly rather than assuming.

## Voice Direction
**None.** No Archivist narration plays anywhere in this video's body.
This is consistent with every prior video's closing annotation
convention (which has always been silent text, never voiced) — what's
different here is that the entire document scroll also carries no
narration, unlike every previous document-reading video.

## Visual Approach
One continuous visual element:

- **[DOCUMENT — CONTINUOUS SCROLL]** — File Zero, a single document,
  scrolling continuously and slowly downward for the majority of the
  runtime. Nearly every line, on every visible page, is covered by a
  black redaction bar. No sections, no headers beyond the file ID
  itself, are legible. The scroll should feel mechanical and
  unhurried — a system reading its own sealed file, not a person
  turning pages.
- One single line near the end of the scroll is NOT redacted. This is
  the video's entire spoken content, and it is read only by the viewer,
  never spoken aloud.

No CRT scan line overlay, no archival grain, no VHS tracking — strip
every recurring visual signature the arc has built up. This document
should look colder and more uniform than any other document in the
series. A very subtle paper-grain texture is acceptable purely so the
image doesn't look like a broken render, but nothing more.

## On-Screen Text
The unredacted line and the closing annotation are the only text in this
video.

## Silence Note
This video has no ambient sound bed anywhere — no drone, no hum, no room
tone. Per the asset list, silence itself is a required asset, not an
absence of one. If the total silence risks reading as a technical error
to viewers, the acceptable fix is an extremely faint, barely perceptible
tape-hiss floor — nothing louder, and nothing that could be mistaken for
an ambient choice. Default to true silence; only add the faintest hiss
if testing shows viewers genuinely can't tell the file is playing.

[BEAT] / [LONG BEAT] markers are not used in this script — there is no
narration to pace against. Hold times are specified directly per beat
instead.

## First Phantom Seed
Per `first-phantom-thread-seed-map.md`: *"This video is the seed. No
hidden detail. For the first time — nothing concealed."* Do not add a
buried Easter egg, a stray legible word among the redaction bars, or any
further puzzle element to this document. Every prior seed in this arc
has been something to notice. This one is the opposite — total,
unambiguous redaction, with exactly one deliberate exception. Adding a
second hidden detail would undercut the entire point.

## Image Transition Note
No dissolves. The scroll is continuous rather than cut between sections.
Transition from the unredacted line into the annotation card is a hard
cut to black, held briefly, before the annotation text fades in.

# DOCUMENT — CONTINUOUS SCROLL

**Duration: approximately 3.5–4.5 minutes, adjustable to hit the 4–6
minute total runtime target once the closing beats are added.**

## [VISUAL]
File Zero fills frame. Minimal header, most of it redacted:

```
HUNTERS DIRECTORATE
[REDACTED]
FILE ID: 0000
CLASSIFICATION: [REDACTED]
DISTRIBUTION: [REDACTED]
```

Below the header, the document continues as page after page of body
text — every line covered by a uniform black redaction bar, consistent
width and spacing throughout, suggesting real sentences and paragraphs
exist underneath but revealing nothing about their structure or length.

Camera performs one continuous, unhurried vertical scroll down through
the full document. Constant speed throughout — no acceleration, no
deceleration, no pause, until the unredacted line is reached. The
scroll should feel like a machine process, not a human turning pages.

**Production note on pacing:** this is the hardest section in the
script to get right, precisely because nothing changes for several
minutes. Recommend testing the scroll speed against the target duration
in CapCut early, since too fast reads as a technical glitch and too slow
becomes genuinely unwatchable rather than tense. A slow, perfectly even
crawl — closer to a security camera's patience than a page-turn — is
the target.

No audio. No page-turn sound. No ambient. Complete silence, or the
faintest acceptable tape-hiss floor per the Silence Note above.
