# Script Expansion Patches — Archive

These are the **script-expansion patch / memo documents** for Videos 03–12,
the ones that describe *where and how* to raise each script from the old
6–8 min runtime target to the new 8–10 min standard.

## Why they're here

On 2026-09-06 these patch documents had been committed *in place of* the
full production scripts (commit `86fd95c` "feature: script expansion"),
overwriting them. The full scripts were recovered from `86fd95c^`
(`3dfa4d3`) and the patch insertions were merged back into them, so the
`media/scripts/script_vXX_*.md` files are once again complete scripts —
now expanded.

These copies are kept only for reference: the rationale, net-effect word
counts, and constraint notes that didn't belong inline in the scripts.

## What the merge folded into each script

- New narration blocks spliced in at each patch's anchor line
- Runtime-target and word-count metadata updated to the new numbers
- A "Script-Expansion Checks" block added to each production checklist
- Every remaining "6–7 / 7–8 / 6–8 minute" runtime reference bumped to
  "8–10 minute"

## Notes per file

- **v11** (`script_v11_echo4_recovered_log`) — this one is a *structural
  memo*, not a word-count patch (the video has zero narration). The merge
  added inline `[EXPANSION — LEVER 1/2/3]` markers at the three
  structural spots; the actual new dialogue still needs to be written to

- **v05** Insertion 4 and **v07/v08/v09** insertions were built by the
