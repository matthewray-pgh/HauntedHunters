## Monetization Alignment (REVISED)

### YouTube Monetization

- **Video length targets: 8-10 minutes standard** (revised from
  6-8 min). This reliably clears the mid-roll ad threshold at 8:00 with

### Why This Matters for Watch Hours (Partner Program path)

Partner Program eligibility requires 1,000 subscribers and 4,000 watch
hours in 12 months. Watch hours = views × average duration watched.
Raising the runtime floor from 6-8 min to 8-10 min — provided retention
holds — increases watch-hours accumulated per view, which shortens the
realistic timeline to eligibility stated elsewhere in this document.
This only holds if the added runtime is genuine content (per the
word-count-driven script approach in `video-pipeline.md`), not padding;
padded runtime risks the opposite effect by suppressing retention and,
with it, mid-roll ad delivery itself.
